# USSD TYAS

A TypeScript-based USSD simulator for Yas services.

## Features

Currently implemented:
   * MVOLA Services
      - Buy credit for my number
      - Money transfer with transaction management

## Prerequisites

   * Node.js 
   * npm

## Installation
- clone this project 
# Install dependencies
npm install
```

## Usage

```bash
npm start
```

## Navigation

   * Use number keys (0-9) to select options
   * Use '*' to go back to previous menu
   * Use '**' to return to main menu
   * Sessions timeout after 10 seconds of inactivity

## Technical Stack

   * TypeScript
   * terminal-kit
   * ESLint
   * Node.js
   * github workflows
